AWS Application Migration Service, MGN in the console and in these notes, moves applications from on-premises or from another cloud into AWS. The notes describe it as the way to make that move faster and cheaper, and to modernise while you are there rather than only copying a disk.

Which R it serves

Rehost — lift and shift — is the strategy MGN is built for. Refactor is a rewrite, and this service does not rewrite the application. DMS is the neighbouring tool when the thing you are moving is a database rather than the whole server. Migration Hub is where you watch either of those projects.

Remember: Application Migration Service moves and replicates servers into AWS. It is the lift-and-shift tool. DMS is the database tool.
