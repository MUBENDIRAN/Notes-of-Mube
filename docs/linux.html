Linux is the kernel at the centre of a Unix-like operating system, together with a shell, an init process, background services and the GNU command-line tools. These notes walk through that layout, the directory tree, permissions, shell scripts, networking, firewalls and the commands used day to day.

1. Overview and architecture

The notes place Linux with Linus Torvalds in Finland, and Unix with Bell Labs in Murray Hill, New Jersey. Torvalds released the Linux kernel in 1991. Unix came earlier, from Bell Labs. Linux is a kernel; a full distribution adds the shell, libraries and the rest of the system around it.

Core components in the notes

KernelLinux. It manages the computer's hardware.
ShellBash, the Bourne Again shell. This is the program that reads the commands you type.
Init systemThe first process the kernel starts. On current Ubuntu and many other distributions that process is systemd, PID 1.
DaemonA background service that runs without an interactive user.
Graphical serverX11 or Wayland. It displays graphics.
Desktop environmentThe graphical interface built on that server.
GNU toolsThe basic command-line utilities, such as the file and text commands later in these notes.

Kernels the notes compare

SystemHow the notes label the kernel
WindowsHybrid. The Windows NT kernel.
macOSHybrid. XNU, a mix of Mach and BSD.

Two names from the same page belong with boot and with the tools:

  • GRUB is the Grand Unified Bootloader.
  • UEFI is the Unified Extensible Firmware Interface.
  • GNU is a recursive name: GNU's Not Unix.

2. Directory hierarchy

Everything in the filesystem hangs from one top directory, /. The notes list the standard directories under it and what each one is for.

/ and /root are different. / is the top of the tree and contains every other directory. /root is the home directory of the root user. It is one directory among the others, not the top of the filesystem. The original notes place both ideas in the same line.
PathRole in the notes
/binBinary executables such as ls, cp, mv and cat.
/sbinSystem binaries such as mount and shutdown. These need superuser privileges.
/libLibraries. Programs load shared libraries from here.
/usrThe notes expand this as Unix System Resources: /usr/bin and /usr/lib, read-only and managed by the system. Historically the name was the user hierarchy. Many current distributions merge /bin into /usr/bin.
/bootFiles required to boot: GRUB and grub.cfg, plus the kernel and initramfs. The notes write “RAM” in this list; that directory does not hold system memory.
/devDevice files. The notes give /dev/tty as the kind of entry that represents a terminal.
/etcSystem configuration as editable text. The notes cite /etc/passwd, the user account list.
/homePer-user files and config, such as .bashrc.
/mediaMount points for removable media such as CDs, DVDs and USB drives on modern systems.
/mntA place for manual mounts, including a remote filesystem you attach yourself.
/procA virtual filesystem. Process IDs appear here as directories, along with kernel status.
/syssysfs, another virtual filesystem, for kernel and device information.
/runTemporary runtime data for the current boot.
/srvData a hosted service provides, such as web content.
/varFiles that change while the system runs. Logs live in /var/log.
/tmpTemporary files created by applications or users. The sticky bit is set here.
/optOptional third-party software, kept out of the core system directories.

The sticky bit on /tmp lets any user create files there, and lets only the file owner (or root) delete or rename that file. Other users cannot remove someone else's temporary files.

The directory layout is documented in hier(7).

4. UFW and cloud firewalls

UFW is the Uncomplicated Firewall, a host firewall used on Ubuntu. The notes treat it as the system-level firewall and contrast it with a cloud security group.

CommandAction in the notes
ufw statusShows the rules.
ufw enableTurns the firewall on.
ufw allow 22Allows SSH, which listens on port 22 by default.
ufw deny 80Blocks HTTP.
ufw delete allow 22Removes that allow rule.

These commands need root, so on Ubuntu they are run with sudo. On a remote machine, allow SSH before you enable UFW. Enabling it with no SSH rule drops the connection you are using.

Security groups

The notes describe a security group as a virtual firewall for an EC2 instance or another cloud service. It decides which ports and IP addresses are allowed inbound and outbound. The source writes “IPS” in the flow; in this section that means IP addresses.

Traffic through a security group
Data coming in→Inbound→Ports and IPs allowed
Ports and IPs allowed→Outbound→Data going out
LevelWhat it filters
UFWThe system. Rules on that Linux machine.
Security groupThe cloud. Rules in front of the instance.

A packet to a cloud instance has to be allowed by the security group and then by the host firewall. Either one can still block it.

5. Shell scripting

A shell script is a text file of commands for the shell, usually Bash. The first line is the shebang. It tells the system which interpreter should run the file.

#!/bin/bash

The notes run a script in two steps: make it executable, then start it.

chmod +x script.sh
./script.sh
bash script.sh

The original notes write chmod +x .sh and sudo bash .sh. sudo is only needed when the script itself needs root. ./script.sh uses the shebang. bash script.sh chooses Bash even if the file is not executable.

Variables

There is no space around =. $ reads the value. The notes remind you that shell variables are strings unless you ask for arithmetic.

#!/bin/bash
name="Bro"
echo "Hello $name"

# Arithmetic uses $(( ))
sum=$((a + b))

User input

#!/bin/bash
read -p "Enter your name: " name
echo "Hello $name"

-p prints the prompt on the same line and stores the answer in name.

Conditions

#!/bin/bash
if [ "$x" -gt 10 ]; then
  echo "big"
else
  echo "small"
fi

The semicolon ends the test when then stays on the same line. It is not part of the comparison itself. Quoting "$x" keeps an empty value from breaking the test. The notes show $x unquoted.

OperatorMeaning in the notes
-eqEqual.
-neNot equal.
-gtGreater than.
-ltLess than.

These operators compare integers. The while loop later uses -le, less than or equal. -ge is greater than or equal. It is not in the original operator list.

6. Loops, functions and awk

Loops from the notes

# For loop
for i in {1..5}; do
  echo "$i"
done

# While loop
count=1
while [ "$count" -le 5 ]; do
  echo "$count"
  ((count++))
done

{1..5} expands to the numbers 1 through 5. ((count++)) adds one. The notes compare that with count += 1 in Python. -le means less than or equal.

Functions and arguments

greet() {
  echo "Hello $1"
}

greet "Bro"
ParameterMeaning
$1First argument.
$2Second argument.
$@All arguments.
$#How many arguments were passed.

awk

The notes introduce awk as a text-processing and reporting language, and name gsub as global substitute.

PieceMeaning in the notes
NRNumber of records. The current line number.
NFNumber of fields on the current line.
$1, $2Columns on the current line.
{ }The commands to run for each line.
BEGIN { }Code that runs before any line is read.
END { }Code that runs after every line has been read.
awk '{ print $1 }' file.txt

That one-liner is the form the notes use later. A line that also uses gsub, BEGIN and END is an additional example:

awk 'BEGIN { print "start" }
{ gsub(/old/, "new"); print NR, $1 }
END { print "fields on the last line:", NF }' file.txt

7. Permissions

Numeric chmod adds three values: read is 4, write is 2, execute is 1. Each digit of the mode is the sum for one class of user. The three digits are owner, group, then others.

PermissionNumber
read (r)4
write (w)2
execute (x)1
ModeWho can do what
400The owner can read. Nobody else can read, write or execute.
644The owner can read and write. Group and others can read.
755The owner can read, write and execute. Group and others can read and execute.
755 does not grant write to other people. The original notes describe 755 as “others can read/write/execute.” Write for the owner only is the 2 in the first digit. Group and others have 5, which is read plus execute. A mode that also gives everyone write is 777, and that is rarely what a normal file should have.

The notes also show the commands that change and inspect this metadata:

chmod 755 script.sh
chown user:group script.sh
stat script.sh

chown user:group sets the owner and the group. stat shows size, permissions and timestamps. The notes phrase the classes as “owner group user other”; user and owner are the same class, so the mode has three digits, not four.

8. Boot and firmware

TermMeaning in the notes
BIOSBasic Input/Output System. The older firmware that starts the machine.
UEFIUnified Extensible Firmware Interface. The firmware that replaced BIOS on current PCs.
MBRMaster Boot Record. The legacy boot record and partition layout at the start of a disk.
GPTGUID Partition Table. The partition layout used with UEFI. It describes how the disk is divided.
GRUBGrand Unified Bootloader. It loads the kernel after the firmware hands off.
GPT here is the partition table. The original notes also expand GPT as ChatGPT and “Generative Pre-trained Transformer.” That is a different use of the same three letters. ChatGPT does not partition a disk. The GPT in this section is the GUID Partition Table.
Boot path the terms describe
BIOS or UEFI→MBR or GPT→GRUB→Linux kernel→Init

Packages

Ubuntu and Debian use APT. The notes' Red Hat and CentOS commands are YUM, and the same subcommands on current Fedora, RHEL and CentOS Stream are DNF.

APTYUM or DNFEffect
apt updateRefreshes the package index. It does not upgrade installed software.

11. Flags, text processing, archives and the environment

The notes list flags as short abbreviations. The same letter does not mean the same thing on every command. df -h is human-readable, while many other commands use -h for help.

FlagMeaning the notes give
-hHelp. Also human-readable on df, du and free, which is how the notes use it earlier.
-vVerbose. More detail about what the command is doing.
-rRecursive. The command walks a directory and its subdirectories.
-fForce. Ignore the usual warnings and proceed. On tail, -f means follow.
-aAll. Include everything, such as hidden files in ls -a.
-lLong listing.
-sSize or summary, as in du -s.
-tTime. ls -lt sorts by modification time.
-iInteractive. rm -i asks before each delete.
-cA format or config switch on some commands. The notes give stat -c '%s', which prints the size in bytes.

Text processing

CommandPurpose in the notes
grep -i, -r, -vSearch. -i ignores case, -r is recursive, -v inverts the match and prints lines that do not match.
awk '{print $1}'Prints the first field of each line.
sed 's/old/new/g'Replaces text. The trailing g replaces every match on the line, not only the first.
sort -n, sort -rSorts lines numerically, or in reverse.
uniq -cCounts adjacent duplicate lines. Sort the input first if you want duplicates grouped.
cut -d, -fExtracts columns. -d sets the delimiter and -f selects the field.
tr -d, tr -sThe notes pair d with delete and s with substitute. tr -d deletes characters. tr -s squeezes repeated characters. Substitution of one set for another is tr SET1 SET2.
wc -l, wc -wCounts lines or words. Without a flag, wc also counts bytes.

Archives

CommandPurpose in the notes
tar -cvf archive.tar filesCreates an archive. c create, v verbose, f the archive name.
tar -xvf archive.tarExtracts it. x is extract.
gzip fileCompresses a file. The notes use gzip -d for decompress.
gzip -d file.gzDecompresses that gzip file.
zip -r archive.zip dirCreates a zip file, recursively.
unzip archive.zipExtracts a zip file.

echo -ePrints a message and interprets backslash escapes.
read -pReads user input with a prompt.

12. Installation paths in the notes

The last page points at three official ways to get a Linux environment. The commands and installers below come from those guides. Read the linked page before you change a disk.

Windows Subsystem for Linux

Microsoft's guide: Install WSL. The notes' quick setup is an administrator PowerShell or Command Prompt:

wsl --install

That installs Ubuntu by default. Restart when Windows asks you to.

Linux as the only system

Ubuntu's desktop guide: Install Ubuntu desktop. The notes' outline is: download the ISO, write it to a USB with Rufus, boot that USB from the firmware boot menu, and choose the install option.

“Erase disk and install Ubuntu” removes what is on that disk. Use it when the machine should boot only Ubuntu. If Windows has to remain, use the dual-boot path instead.

Dual boot with Windows

The notes link to help.ubuntu.com/community/WindowsDualBoot. That community page no longer resolves. The current desktop tutorial covers the same choice: Install Ubuntu desktop. The notes' outline is: shrink the Windows partition in Disk Management so there is unallocated space, boot the USB installer, and choose “Install Ubuntu alongside Windows.” If BitLocker is on, the installer cannot see the Windows partitions until it is turned off. Ubuntu documents that case in BitLocker during Ubuntu installation.
